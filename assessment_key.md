# Assessment Key for AI-Generated School Materials

**Scale:** 1 to 10 points.
**Usage:** Evaluate the AI-generated content against the provided Source Text based on these criteria.

---

### 1. Source Fidelity (Quellentreue)
*Did the AI stick strictly to the provided text?*

| Score | Criteria |
| :--- | :--- |
| **10 (Perfect)** | 100% of information is found in the source text. No outside facts, no assumptions. |
| **7-9 (High)** | Uses source text, but adds 1-2 minor "general knowledge" facts that are harmless (e.g., "The sun is hot"). |
| **4-6 (Mid)** | Drifts from text. Includes significant outside info (names, dates, concepts not in source). |
| **1-3 (Low)** | Massive hallucination. Invents facts, contradicts source, or writes about a different topic entirely. |

---

### 2. Logical Coherence (Logische Kohärenz)
*Does the material make sense as a teaching tool?*

| Score | Criteria |
| :--- | :--- |
| **10 (Perfect)** | Questions flow logically. Instructions are crystal clear. No grammatical errors. |
| **7-9 (High)** | Readable and clear, but maybe one question is slightly phrased awkwardly. |
| **4-6 (Mid)** | confusing phrasing. Questions refer to "the previous paragraph" which doesn't exist. |
| **1-3 (Low)** | Word salad. Broken sentences. Unintelligible. |

---

### 3. Answer Accuracy (Lösungskorrektheit)
*Is the provided answer key correct based on the text?*

| Score | Criteria |
| :--- | :--- |
| **10 (Perfect)** | Key is 100% correct. Matches the questions perfectly. |
| **7-9 (High)** | Key is correct, but maybe one answer is ambiguous/debatable. |
| **4-6 (Mid)** | Key has 1-2 clear errors (e.g., says "A" is correct when it's "B"). |
| **1-3 (Low)** | Key is missing, completely wrong, or belongs to a different test. |

---

### 4. Structure Compliance (Struktureinhaltung)
*Did it follow the requested format?*

| Score | Criteria |
| :--- | :--- |
| **10 (Perfect)** | Matches template exactly (Title, Summary, Questions, Key). |
| **7-9 (High)** | All sections present, but maybe formatting (bolding/lists) is sloppy. |
| **4-6 (Mid)** | Missing a minor section (e.g., forgot the "Summary"). |
| **1-3 (Low)** | Completely ignored format. Just dumped a block of text. |

---

### 5. Language Fluency (Sprachfluss - German)
*Is the German natural and appropriate for school?*

| Score | Criteria |
| :--- | :--- |
| **10 (Perfect)** | Native-level German. Appropriate academic tone. No anglicisms. |
| **7-9 (High)** | Good German, minor "translationese" (awkward phrasing) but grammatically correct. |
| **4-6 (Mid)** | Obvious machine translation. Wrong genders, false friends ("Eventuell" used as "Eventually"). |
| **1-3 (Low)** | Broken German, mixed with English, or incomprehensible. |

---

### 6. Topic Coverage (Themenabdeckung)
*Did it use the whole document?*

| Score | Criteria |
| :--- | :--- |
| **10 (Perfect)** | Questions cover the beginning, middle, and end of the text. Balanced focus. |
| **7-9 (High)** | Good coverage, but ignores one minor section. |
| **4-6 (Mid)** | Lazy. Questions only ask about the first paragraph or the title. |
| **1-3 (Low)** | Random coverage. Asks 5 questions about one tiny footnote. |

---

### 7. Difficulty Differentiation (Schwierigkeitsgrad)
*Did "Level 2" actually test deep understanding?*

| Score | Criteria |
| :--- | :--- |
| **10 (Perfect)** | **Level 1:** Pure recall. **Level 2:** Requires synthesis/logic. Distinct difference. |
| **7-9 (High)** | Level 2 is harder, but maybe just "harder facts" rather than "deep logic." |
| **4-6 (Mid)** | No difference. Level 2 is just Level 1 with more words. |
| **1-3 (Low)** | Level 2 is easier than Level 1, or completely fails to be difficult. |
